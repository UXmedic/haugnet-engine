# devlog directory description

This directory contains all the development logs and plans for the project. Most of the output found in this directory is generated by the AI agents. Journal entries could also be added manually, and plans might have user input adjustments to fine tune them.

Once a plan is approved it will be translated into action items and mapped to specifications to be populated in `docs/specs/spec_<short-description>.md` and mark each spec as implemented when its developed, tests prepared (unit tests, integration tests, e2e tests, whichever applicable), all tests passing, documented and deployed.

Definition of done: 
- Specification is fully described highlighting the respective use case scenario
- Tests are prepared (unit tests, integration tests, e2e tests, whichever applicable)
- Specification is implemented and configured behind a feature flag
- All tests are passing
- Usage metrics are integrated when applicable
- Documentation is prepared
- Deployment is completed
